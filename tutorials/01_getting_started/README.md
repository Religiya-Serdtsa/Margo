# 01. Getting Started

가장 단순한 `Margo` 프로그램을 통해 빌드 파이프라인을 익힌다.

## 학습 목표
- `@import`와 `fn start` 시그니처를 작성한다.
- `print()`를 이용해 문자열을 출력하고 종료 코드를 반환한다.
- 튜토리얼의 `Makefile`을 사용해 예제를 빌드/실행한다.

## 실행 방법
```bash
cd tutorials/01_getting_started
make            # example 바이너리 생성
./example
```

터미널에는 `Hello, Margo builders!` 문구가 표시된다.
