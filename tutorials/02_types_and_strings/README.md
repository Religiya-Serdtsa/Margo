# 02. Types & Strings

자동 타입(`auto`), `string` 별칭, `weird(T, n)` 포인터 축약을 조합해 함수 인자와 지역 변수를 선언하는 방법을 다룬다.

## 학습 목표
- `string` 별칭을 이용해 C 스타일 문자열을 선언한다.
- `auto`를 사용해 반복적으로 등장하는 타입 표기를 생략한다.
- `weird(T, n)`로 다중 포인터를 간결하게 표현한다.
- 여러 값을 `print()`에 넘길 때의 자동 구분자 동작을 확인한다.

## 실행 방법
```bash
cd tutorials/02_types_and_strings
make && ./example
```
